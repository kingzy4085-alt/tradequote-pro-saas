# ModuleTile

A small link tile to one operational module; hover turns it amber.

Hand-written from the Core Operational Modules grid in `app/page.tsx`.

## When to use
The Command Center's module grid (6 / 4 / 3 / 2 columns, gap `space-3`), inside a roomy Panel.

## Consumer provides
`href` and the module's short name as the crew says it: "LOTO Permits", "Tool Crib", "Site Vault".
