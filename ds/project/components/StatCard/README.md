# StatCard

A dashboard metric: uppercase label, a large figure, one amber caption.

Hand-written from the metrics grid in `app/page.tsx`.

## When to use
The Command Center metrics grid (3 / 2 / 1 columns, gap `space-6`). Counts only, one per card.

## Consumer provides
`label`, `value`, a `caption` that says what is counted ("Facility accounts & contacts"), and `loading` while fetching ("..." is shown).
